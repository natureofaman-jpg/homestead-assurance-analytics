# Homestead Assurance Company

## A Synthetic Insurance Data Engineering & Analytics Project

### Project Introduction

Homestead Assurance Company is a fictional life insurance provider built to simulate data, systems, and operational challenges of a real world insurance business.

The goal of this project is to design and develop a full data engineering and analytics environment. Rather than working with a static dataset, this project uses Python to generate synthetic business data based on configurable product rules, policy lifecycles, and business scenarios.

### Why I built this

I want to continue my journey to becoming a data/analytics engineer by hosting personal projects on GitHub. I have remained passionate about Life Insurance to this day. Having previously worked as a Team Lead for Fixed and Indexed products, I grew to have an appreciation for different products and the inner workings of the industry.

I have searched for public datasets to create projects within that field and have unfortunately found nothing that matches the vision of what I'd like to work on. I believe domain expertise and interest in your work is what truly elevates projects. Rather than work with other public datasets, I decided to create my own synthetic company using Python. 

This first project will serve to create a repeatable, evolving dataset and database that simulates the lifecycle of an insurance business. Real data is messy and fragmented, and eventually this generator will allow for custom error injection to recreate real life engineering problems that require different resolutions ranging from minor to critical.

### Project Objectives

- Design a realistic insurance company and supporting data structures.

- Generate reproducible synthetic policies, customer databases, etc.

- Simulate multiple source systems and ingestion methods.

- Develop a Bronze, Silver, and Gold data architecture.

- Implement SQL transformations, data quality checks, and validation.

- Build dimensional models and business intelligence reporting.

- Introduce realistic data inconsistencies and edge cases to test pipeline resilience.
